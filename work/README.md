# Case study template

Duplicate `lemfi-credit.html` for each new project:

1. Save as `work/<slug>.html` (slug = lowercase, hyphens, e.g. `zazuu`)
2. Add images under `assets/projects/<slug>/`
3. In `index.html`, update the project in `projects()`:
   - Add `image: 'assets/projects/<slug>/preview.svg'`
   - Remove `soon: true` when ready to publish
   - Set `cta: 'View Work'`
